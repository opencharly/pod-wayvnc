# 2026.323.1735 — feat(wayvnc): install on Arch/CachyOS; compositor-agnostic wrapper; power-on workaround only for wayvnc <= 0.9.1

## Summary

The wayvnc candy now installs on **Arch/CachyOS**, and its wrapper no longer assumes sway. Closes opencharly/pod-wayvnc#6. This is the producer for pod-kde-vnc (opencharly/opencharly#1171), which bases on `pod-cdi` (CachyOS).

| file | change |
|---|---|
| `charly.yml` | adds the `arch:` package entry; CachyOS inherits it, and Arch ships wayvnc **0.10.2**, the latest upstream release. Adds the `wayvnc-wrapper-generic` build check. |
| `wayvnc-wrapper` | waits only on `$XDG_RUNTIME_DIR/$WAYLAND_DISPLAY`. Waits for sway's IPC socket only when sway runs. `-o` comes from `WAYVNC_OUTPUT` and is omitted when unset (wayvnc then serves its first output, which is `HEADLESS-1` on a headless sway, so existing consumers are unchanged). The headless power-on workaround now runs **only for wayvnc <= 0.9.1**. |
| `.agents/skills/wayvnc/SKILL.md` | documents the version-gated workaround and the compositor-agnostic wrapper. |

Why the workaround is gated rather than deleted: wayvnc 0.10.2 on headless sway 1.12 serves a full frame without it (measured, below). Fedora 43/44, Debian 13 and Ubuntu 25.x still ship 0.9.1, which needs it. Its deletion is tracked in opencharly/distro-fedora#130.
